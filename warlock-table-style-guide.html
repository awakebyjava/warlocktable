Warlock Table — Visual Identity

Clean Occult

A style system drawn directly from the table itself — matte black, brass inlay, sigil geometry, and the purple of the chair gems. Disciplined and ceremonial, not broken. The strangeness lives in what it says, not in how it renders.

III. Marks

One icon family, built from the same rule as the table's two inlaid sigils: a circular frame, radial symmetry, one glyph at the center that names the function. Clean construction — the sigils carry meaning through symbolism, not through distortion.

  • → Every mark shares the same 26px circular frame — that consistency is the "family," not a shared decorative flourish.
  • → Brass ring = the mark exists / is available. Purple = the mark is currently active. Muted bone = disabled or unavailable.
  • → No skulls, no pentagrams-as-cliché, no dripping textures. The real sigils on the table are elegant line diagrams — the icon set should read as instruments, not Halloween clip art.

V. The Signature

The sigil ring is the one recurring mark across the whole system — favicon, loading state, the frame around the entity's "currently speaking" indicator, a watermark on session recaps. One geometric form, reused with intention, never redrawn differently twice. It's the thing this brand is remembered by, the same way the two sigils are the first thing you see on the table itself.
